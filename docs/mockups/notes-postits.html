3 · Abrir uma nota

Editor simples — título opcional + corpo. Sem checklist de tarefa, sem prioridade, sem projeto obrigatório.

Editor (sheet / push)

21:48

mint âmbar violeta cinza rosa
Virar tarefa Excluir

Bridge com Stacked: “Virar tarefa” cria uma task com o texto como título/descrição e pergunta o projeto. A nota pode sumir ou ficar linkada.

O que NÃO é

≠ descrição de tarefa ≠ subtarefa ≠ comentário ≠ projeto kanban

Hoje a “nota rápida” vive dentro da tarefa (campo descrição). Isso continua. Este quadro é para ideias sem dono de tarefa ainda — o papel solto na mesa, não o post-it colado no card do Kanban de projeto.

Modelo mental:
Tarefa = compromisso com ação.
Nota = pensamento capturado.
