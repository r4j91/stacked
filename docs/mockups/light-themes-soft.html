Sugestão de direção

  1. Fog como tema claro principal: mesma personalidade do Graphite, só invertido. Zero branco, camadas claras.
  2. Seafoam como variante “de marca”: quem gosta do accent ciano vai sentir o tema coerente.
  3. Cloud se a dor for brilho (outdoor / OLED): claro o bastante, sem estourar.
  4. Limestone / Pearl como opcionais quente vs frio, se quiserem família maior.
  5. Moonstone pode ficar, ou migrar surface de #FFFFFF → #EEEFF3 (virar Fog).
